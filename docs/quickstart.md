# Quickstart (Server Admin)

This guide helps non-developers set up the plugin on a Paper server.

## 1) Prerequisites

- Paper 1.21.x (recommended)
- Java 21

## 2) Install the Plugin

1. Download the latest Raid Extraction jar.
2. Drop it into `plugins/`.
3. Start the server once to generate the config folder.

## 3) Configure

All configs live at `plugins/RaidExtraction/`:

- `config.yml` — global settings, lobby/raid worlds, evac duration.
- `raids.yml` — raid definitions (players, timers, evac zones, loot table per raid).
- `loot_tables.yml` — weighted loot entries.
- `items.yml` — custom weapons, mods, spells, and mana settings.
- `locations.yml` — generated by the in-game map editor (spawn points, evac zones, loot containers).

See [configuration.md](configuration.md) for file-by-file details and examples.

## 4) First Run Checklist

1. Confirm `lobbyWorld`, `lobbySpawn`, and `raidWorld` in `config.yml`.
2. Update `raids.yml` with your raid definitions and min/max players.
3. Use `/raidadmin edit <raidId>` to define spawn points, evac zones, and loot containers.
4. Start a raid with `/raid join <raidId>` and validate extraction flow.

## 5) Troubleshooting

- Check `logs/latest.log` for plugin startup messages and warnings.
- Validate editor data with `/raidadmin validate <raidId>`.
- If loot feels empty, confirm `target_loot_count` and loot container locations.
